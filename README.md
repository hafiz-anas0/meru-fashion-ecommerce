# MERU — Fashion & Lifestyle

A modern, full-stack fashion and lifestyle e-commerce platform built for Pakistani men and women.

MERU is being developed as a production-ready e-commerce product with a focus on clean design, scalable architecture, secure authentication, seamless shopping, payments, real-time features, and a complete admin dashboard.

## Tech Stack

### Frontend

* Next.js
* TypeScript
* React
* Tailwind CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

### Planned Integrations

* Stripe
* Cloudinary
* Firebase
* WebSocket / Socket.IO
* Email service
